Contribute

Good ideas improve through collaboration.

There are different ways to take part in Open Sifric projects: reading code, reporting reproducible bugs, proposing improvements, improving documentation, or contributing a change.

Before you begin

  1. 1

    Choose a public repository from the Sifric organization on GitHub.

  2. 2

    Read its README, license, contribution guidelines, and open issues.

  3. 3

    Check whether the project is accepting contributions.

  4. 4

    For larger changes, open an issue to discuss the approach before implementing it.

  5. 5

    Keep pull requests focused, explain the change, and include relevant testing details where possible.

Reporting issues

Describe what happened, what you expected, and how to reproduce the issue. Include version and environment details where relevant. Avoid posting credentials, private data, or security-sensitive details publicly.

Security concerns

Do not disclose exploitable vulnerabilities in public issues. Check the repository's security policy for a private reporting channel. If none exists, avoid posting sensitive technical details publicly until a safe contact method is available.

Licensing

Publicly visible source code is not automatically open-source licensed. Review the license of each repository before copying, redistributing, or modifying code.

About Open Sifric

A place for software built in the open.

Open Sifric is the open-source initiative of Sifric Platforms, an independent technology brand focused on software engineering and digital products.

We use this initiative to share public projects, engineering experiments, developer resources, and ideas worth exploring together.

Our purpose

Make useful software and technical knowledge easier to discover, understand, and improve.

We aim to build with care: readable code, thoughtful architecture, responsible security practices, and documentation that helps others get started.

Our focus

Our areas of interest include developer tooling, libraries, web and mobile technologies, APIs, backend systems, and cloud infrastructure.

These are areas of focus, not claims that published projects exist in every category.

About Sifric Platforms

Sifric Platforms is an independent technology brand based in Sri Lanka. Open Sifric is one part of its wider interest in building practical software and digital platforms.
